# Sponsor qualification work

on 7 November 2026. Evidence is not a guarantee of judging or eligibility.

## EF CROPS

1. Public GitHub visibility confirmed through the GitHub API; root MIT license
   and runnable setup are present.
2. Root README includes C/O/P/S and server-storage/privacy trade-offs.
3. `evidence/crops/crops-recovery.webm` records local contract recovery through
   the actual static page after the dashboard host stops. The automated EIP-1193
   fixture is not a manual browser-extension or live-chain demonstration.
4. Server provider-key/research storage is disclosed. Standalone recovery has
   local-only network evidence. Authenticated Privy SDK analytics remain an open
   whole-client qualification issue; removing decorative remote media does not
   resolve vendor telemetry. The team explicitly chose to retain Privy with
   wallet-only sign-in; email login/automatic embedded wallet creation are off.
5. The team confirms CROPS is its only intended EF prize. Final submission and
   prize placement are external to the repository.

## Hedera

1. The current native exact scheme uses the official SDK and now passes offline
   HTTP/signature/price/replay tests. Prior executor payment evidence is a
   different protocol path and cannot establish native exact compliance.
2. The native client pays automatically under a pinned policy. Live acceptance
   and video await locally configured funded testnet accounts; no keys are in
   this checkout at implementation time.
3. Root README now covers setup, architecture, HTTP payment flow and the exact
   historical Hedera transaction ID with a HashScan link. New live evidence
   will be added separately after actual native settlement.
4. `npm run x402:live --prefix backend` records a live payment/replay and public
   Mirror result, without publishing signed payloads. A video is not claimed
   complete until that command succeeds with funded credentials.

Optional HCS identity/logging, A2A/ACP, Scheduled Transactions and Agent Kit/MCP
bonuses are not mandatory qualifications and remain unimplemented. Existing
TaskTreasury controls and historical HTS USDC proof are separate from native
exact endpoint policy. See `evidence/sponsor-status.json`; recorded experiments
are distinct from independent sponsor approval.
